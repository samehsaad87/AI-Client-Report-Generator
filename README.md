# AI Client Report Generator

Transforms raw client/project notes into a structured professional report and saves it automatically.

## Technologies
Python, OpenAI API, python-dotenv

## Automation Flow
Notes → OpenAI analysis → structured report → TXT file

## Run
`pip install -r requirements.txt`
Create `.env` from `.env.example`, then run `python main.py`.

## Portfolio Focus
AI-assisted business reporting and document automation.
